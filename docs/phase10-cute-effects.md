# 第10フェーズ実装ドキュメント — チワワに特化した可愛い演出

作成日: 2026-07-05
ステータス: 実装完了

## 目的・スコープ

START.md 第10フェーズ「チワワに特化した可愛い演出を追加する（仕様未定）」について、
以下の4項目を実装する（ユーザー確認済み）。

1. **チワワを大きくする** — 電車に乗っている うる・ろい を約1.4倍に拡大
2. **走行中の「ゆれ」アニメ** — 走行中だけ2匹が小刻みにぴょこぴょこ揺れる
3. **到着演出** — 到着時に2匹がしっぽふりふり風に喜び、「わん！」の吹き出し＋肉球がはじける
4. **肉球の足あと** — 走行中、電車の通った線路に肉球の足あとが残ってフェードアウト

対象はゲーム画面の電車スプライト（`Train.tsx`）まわりのみ。
データモデル・ストアのロジック変更はなし。

## 実装内容

### 1. チワワの拡大（Train.tsx）

- 窓から乗り出す うる・ろい を 48×46px → **66×63px（約1.4倍）** に拡大
- 各窓の中心（x = ±30）に合わせて配置し、頭が車体からさらに大きくはみ出す構図に
- `image-rendering: pixelated` はそのままでドット感を維持

### 2. 走行中のゆれ（Train.tsx + index.css）

- ストアの `isMoving` を購読し、走行中のみチワワの `<g>` に `.chiwawa-ride` を付与
- `chiwawa-ride`: translateY で上下にぴょこぴょこ（0.45s / `steps(2)` でピクセル調のカクカク感。
  既存の `.bob` と同じ流儀）
- 2匹目は `animation-delay` で位相をずらし、交互に跳ねる

### 3. 到着演出（Train.tsx + index.css）

到着フラグはストア既存の `arrivedIndex`（駅タップ移動の到着時に2.2秒立つ）をそのまま使用。

- **しっぽふりふり風**: 到着中はチワワに `.chiwawa-happy` を付与。
  足元を支点（transform-origin: 下部）に左右へ高速に振れる回転アニメ
- **「わん！」吹き出し**: 電車の上に吹き出し（角丸矩形＋しっぽ）を表示。
  `pop-in` アニメでぽんっと出現
- **肉球バースト**: 🐾 を6個、電車の中心から放射状に飛ばしてフェードアウト
  （CSS変数 `--dx` / `--dy` で各ピースの飛び先を指定）
- 吹き出しと肉球は、車体の回転・左右反転の影響を受けない**別レイヤー**
  （translate のみの `motion.g`）に描画し、常に正立で読めるようにする
- `key={arrivedIndex}` で到着のたびにアニメーションを再生

### 4. 肉球の足あと（Train.tsx + index.css）

- 走行中、280ms 間隔で電車の現在位置（Framer Motion の `pos` の実数値）から
  足あとをスポーン
- 進行方向に対して左右交互に約10pxずらし、歩幅っぽいジグザグに
- 足あとは SVG の小さな肉球（パッド楕円＋指3つ、ピンク）で、線路の角度に合わせて回転
- 1.6秒かけてフェードアウトして消える（最大12個まで保持）
- 電車より**下のレイヤー**に描画（電車 `<motion.g>` より前に出力）

## 仕様解釈・判断メモ

- 「しっぽふりふり」はスプライトが1枚画像のため、体全体を足元支点で左右に振る表現で代替
- 到着演出は従来どおり**駅タップ移動の到着時のみ**（▶ボタン・自動再生の停車では出さない。
  既存の `arrivedIndex` の挙動に合わせた）
- 足あと・吹き出しは環状（LoopMap）・直線（LinearMap）どちらでも動作
  （`along` コールバック経由で座標を得るため地図レイアウトに依存しない）
- 地図中央（CenterInfo）のチワワ表示は既存の `.bob` のまま変更しない
