# 第3フェーズ実装ドキュメント — スタート駅選択・駅名フリーワード検索

作成日: 2026-07-04
ステータス: 実装完了

## 目的・スコープ

タイトル画面でスタート駅を選択できるようにする。

- フリーワードで駅名を検索（部分一致）
- 複数ヒットした場合は候補一覧から選ぶ
  - 候補は「路線 × 駅」単位で表示（例: 渋谷 → JR山手線 渋谷 / 銀座線 渋谷 / 東急東横線 渋谷）
- 選択した駅・路線からゲームを開始する
- 未選択の場合は従来どおり JR山手線・東京駅スタート

検索対象は**乗車可能5路線**（山手線・銀座線・丸ノ内線・日比谷線・東横線）の全117駅。
案内のみの路線（JR他線・都営など）はスタート駅に選べないため検索対象外。

## 主要な設計判断

### 1. React Router は導入しない

第1フェーズのドキュメントで「第3フェーズ（駅検索・URL共有）で導入予定」としていたが、
START.md の第3フェーズ要件は「タイトル画面でのスタート駅選択」のみで URL 共有は含まれない。
画面は引き続きタイトル⇔ゲームの2枚で state 切替のまま十分なため、導入を見送った
（URL共有が要件化されたタイミングで導入する）。

### 2. 検索ロジック（src/data/search.ts ★新規）

```ts
interface SearchHit {
  lineId: RideableLineId
  line: RideableLine
  index: number     // その路線での駅インデックス
  station: Station
}
searchStations(query: string): SearchHit[]
```

- RIDEABLE の全路線・全駅を走査し、`name` / `kana` / `en` / `number`（駅ナンバリング）の
  いずれかに**部分一致**した駅を返す
- 正規化: 小文字化・空白除去・**カタカナ→ひらがな変換**（「シブヤ」でも「しぶや」でもヒット）、
  クエリ末尾の「駅」を除去（「渋谷駅」→「渋谷」）
- 並び順: 完全一致 → 前方一致 → 部分一致 の順にスコアリングし、
  同スコア内は路線の定義順（山手線が先頭）
- 全駅数が117と小さいため、インデックス構築などはせず毎回線形走査で十分

### 3. ストア変更（store.ts）

- `startGame(start?: { lineId; index })` に引数を追加。
  指定があればその路線・駅で、なければ山手線・東京駅でゲーム画面へ
- 方向は常に `fwd` で開始（どちら向きに乗るかをユーザーが選ぶ、という本アプリの目的どおり）

### 4. タイトル画面のUI（TitleScreen.tsx）

- タイトルロゴとStartボタンの間に「しゅっぱつ駅」パネル（ガラス調 `.panel`）を追加
  - 現在の選択を大きく表示（路線バッジ + 駅名 + かな + 駅ナンバリング）
  - 初期値は JR山手線 東京（JY01）
- 検索ボックス: 入力のたびに `searchStations` を実行し候補を即時表示
  - 候補行 = ラインカラーのバー + 路線名 + 駅名 + かな + 駅番号バッジ（タップで選択）
  - 選択すると入力欄をクリアして候補を閉じ、「しゅっぱつ駅」表示を更新
  - 0件時は「みつかりませんでした」を表示
  - 候補が多い場合はリスト内スクロール（max-height）
- 選択状態は TitleScreen のローカル state（タイトルに戻ると東京駅にリセット。
  ゲーム側のリセット挙動と一貫）

## 仕様解釈・判断メモ

- START.md の例「JR渋谷駅、東横線渋谷駅、東京メトロ銀座線渋谷駅」→
  同名駅を路線ごとに別候補として出す、と解釈（本実装では 3件ヒット）
- 検索は乗車可能路線のみを対象とした。案内のみの路線を出しても
  スタート駅に選べず混乱するため
- ローマ字入力は駅データの `en`（ヘボン式）との部分一致で対応
  （例: "shibuya" → 渋谷。かな⇔ローマ字変換までは行わない）
- 駅ナンバリング検索（例: "JY01"、"g09"）もおまけで対応（`number` を検索対象に含めた）

## 動作確認（実施済み）

ブラウザ（デスクトップ1280px / モバイル390px幅）で以下を確認:

- 「渋谷」で3件ヒット（山手線 JY20 / 銀座線 G01 / 東急東横線 TY01）、
  東横線 渋谷を選択してスタート → 東横線 TY01 渋谷から開始（方向選択・乗換チップも正常）
- 「シブヤ」「shibuya」「渋谷駅」でも同じ3件がヒット（正規化の確認）
- 「ぎんざ」で銀座（銀座線 G09 / 丸ノ内線 M16 / 日比谷線 H09）+ 東銀座（H10）がヒットし、
  完全一致が部分一致より先に並ぶ
- 未選択のまま Start → 従来どおり山手線・東京駅（JY01）から開始
- 0件クエリ（「大阪」）で「みつかりませんでした」表示
- ゲームからタイトルに戻ると選択が東京駅にリセットされる
- モバイル幅でパネル・候補リストが崩れないこと
