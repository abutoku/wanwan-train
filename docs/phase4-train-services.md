# 第4フェーズ実装ドキュメント — 快速・特快などの停車駅表示

作成日: 2026-07-04
ステータス: 実装完了

## 目的・スコープ

「快速、特快などの停車駅がわかるようにする」（START.md 第4フェーズ）。

スコープはユーザー確認済み:

1. **JR中央線（快速）を乗車可能路線として新規追加**（東京 JC01 〜 高尾 JC24 の24駅）
   - 「快速・特快」の文言どおりの路線を体験できるようにするため
2. **種別（快速・特快・急行など）は停車駅の表示のみ**
   - 種別セレクタで種別を選ぶと、地図上で通過駅がうすく表示され停車駅がわかる
   - 電車の走行は従来どおり各駅停車のまま（種別選択で通過運転はしない）
3. 既存路線では**東急東横線**に種別（各駅停車・急行・通勤特急・特急）を追加
   - 山手線・銀座線・丸ノ内線・日比谷線は全列車各駅停車のため種別なし（UI非表示）

## 収録する種別と停車駅

### JR中央線（快速） — 東京〜高尾

| 種別 | 停車駅 | 備考 |
|---|---|---|

- 特急あずさ・かいじ等（特急券が必要な列車）は対象外

## 主要な設計判断

### 1. データモデル: ServiceType（types.ts）

```ts
interface ServiceType {
  id: string
  name: string          // 例: 中央特快
  color: string         // 種別カラー
  textColor: string
  note?: string         // 例: 平日朝・東京方面のみ運転
  stops: 'all' | string[]  // 'all' = 全駅停車 / 停車駅の station id リスト
}
RideableLine.services?: ServiceType[]  // 先頭 = 全駅停車の基本種別。未定義 = 種別なし
```

- 停車駅は station id で保持（インデックスに依存しないため駅追加に強い）
- `services` の先頭要素を「基本種別」とし、路線切替時のデフォルト選択にする

### 2. ストア: 選択中の種別（store.ts）

```
serviceId: string | null   // 停車駅ビューで選択中の種別（種別のない路線は null）
setService(id)
```

- `startGame` / `transferTo` / `backToTitle` で移動先路線の基本種別にリセット

### 3. UI

- **ServicePicker（新規）**: 種別チップのセレクタ。種別のある路線でのみ表示。
  選択中種別の停車駅数・通過駅数と備考（運転時間帯など）を表示
- **LinearMap**: 選択種別が通過する駅を小さくうすいドット＋うすいラベルで表示、
  停車駅には種別カラーのリングを表示（基本種別=全駅停車の間は従来表示のまま）。
  通過駅もタップ移動は従来どおり可能（表示のみの機能のため）
- **InfoPanel**: 現在駅に「この駅にとまる電車」欄を追加。
  種別ごとに「とまる（種別カラーのバッジ）／通過（グレー）」を一覧表示
- 環状路線（LoopMap）は種別を持つ路線がないため変更なし

### 4. 中央線追加に伴う乗換ネットワーク

- レジストリキーは既存の `LineId` **`chuoRapid`** を使用 →
  既存路線の乗換チップ（山手線 東京・神田・新宿、丸ノ内線 荻窪・新宿・四ツ谷・東京・御茶ノ水、
  銀座線 神田）が駅名マッチングで自動的に「のりかえ →」（タップ可能）になる
- `lines.ts` に案内用路線を追加: JR青梅線（立川）・京王高尾線（高尾）
- 収録見送り（案内チップなし）: 西武多摩川線（武蔵境）・西武国分寺線/多摩湖線（国分寺）・
  JR武蔵野線（西国分寺）・JR八高線（八王子）・多摩都市モノレール（立川ほか）
  → ラインカラーの正確な出典が確認でき次第追加する
- 駅名検索（search.ts）は RIDEABLE を走査しているため自動で中央線24駅が対象に入る
  （検索対象 117駅 → 141駅）

## 仕様解釈・判断メモ

- 「停車駅がわかるようにする」→ 種別を選んで地図上で停車駅／通過駅を見比べられる
  「停車駅ビュー」として実装（ユーザー確認により表示のみ。通過運転は将来の拡張候補）
- 快速の平日／土休日で停車駅が変わる（杉並3駅問題）は、別々の種別チップとして収録し
  旅行者が乗る土休日ダイヤでも正しい停車駅がわかるようにした
- 通勤特快・通勤特急など運転時間帯が限られる種別は `note` で補足表示する
- 中央線の各駅停車（中央・総武線各停）は別路線のため、本路線の種別としては持たない
  （御茶ノ水〜三鷹の各駅には乗換チップ `sobuLocal` で案内）

## 動作確認（実施済み）

ブラウザ（デスクトップ1200px / モバイル390px幅）で以下を確認:

- タイトル検索「たちかわ」→ 中央線 立川（JC19）からスタート。つづら折り24駅マップ・
  立川で青梅線/南武線の案内チップを表示
- 中央特快に切り替え → 「停車 14 駅 ／ 通過 10 駅」、高円寺〜西荻窪・武蔵境〜国立などの
  通過駅がうすく表示され、停車駅に青いリングが付く（停車駅表と一致）
- 通勤特快 → 「停車 9 駅 ／ 通過 15 駅」+ 注記「平日の朝・東京方面のみ運転」を表示
- 山手線 東京 → 中央線チップが「のりかえ →」になり、タップで JC01 東京に乗り換え。
  乗り換え後の種別は基本種別（快速（平日））にリセット
- 東横線 特急 → 「停車 6 駅 ／ 通過 15 駅」、渋谷・中目黒・自由が丘・武蔵小杉・菊名・横浜に
  オレンジのリング。InfoPanel の「この駅にとまる電車」で とまる=カラーバッジ／通過=グレー打消
- 山手線（種別なし）で ServicePicker・「この駅にとまる電車」欄が表示されないこと
- 通過駅の駅タップ移動が従来どおり動作すること
- モバイル幅（390px）でセレクタ・チップのレイアウトが崩れないこと
- `npm run build`（型チェック含む）が通ること
