## 収録区間の判断（スコープ）

実路線が長大・分岐するものは、東京圏の利用で意味のある区間に絞って収録した
（第2フェーズ「丸ノ内線は本線のみ」と同じ判断）。

- **大江戸線**: 実際は「6の字」運転（都庁前で環状部が接続）だが、駅ナンバリング順
  E01 新宿西口 → E38 光が丘 が物理的に連続した経路になっているため、**直線路線として収録**。
  都庁前 ⟷ 新宿西口 間の環状接続（ショートカット）は非対応。
- **湘南新宿ライン**: 駅ナンバリング（JS）が付与されている 大船〜大宮 間。
  逗子方面・小田原方面など大船以南の分岐は収録しない。
- **京急本線**: 品川〜横浜。空港線（KK12〜17）・大師線（KK21〜26）は駅番号が欠番になる
  （本線の駅番号をそのまま使用）。泉岳寺・横浜以南は収録しない。
- **横須賀線**: 久里浜〜東京（JO01〜JO19）。総武快速線への直通部分は収録しない。
  LineId は既存の乗換マスタと共通の `yokosukaSobu` を使い、表示名は「JR横須賀線」とする。
- **京浜東北・根岸線**: 直通運転している根岸線を含む全区間（大船〜大宮）。
  乗換マスタの表示名も「JR京浜東北・根岸線」に更新。

## 種別（停車駅ビュー）の収録

第4フェーズの `services` の仕組みをそのまま使用。主なもの:

- **京浜東北線 快速**: 日中のみ田端〜浜松町間で快速運転。西日暮里・日暮里・鶯谷・御徒町・
  有楽町・新橋を通過（土休日は御徒町にも停車 → 注記で表現）
- **湘南新宿ライン**: 普通（横須賀線直通）は全駅停車。快速・特別快速（東海道線直通）は
  西大井・新川崎・保土ケ谷・東戸塚を通過。特別快速との差は大船以南のため注記で補足
- **副都心線 急行**: 和光市・小竹向原・池袋・新宿三丁目・渋谷（土休日は明治神宮前にも停車 → 注記）
- **浅草線 エアポート快特**: 泉岳寺〜押上間で運転（西馬込発着なし → 注記）
- **京急 快特/特急**、**田園都市線 急行/準急**、**みなとみらい線 特急/急行**（東横線直通）

`oedo.ts` / `asakusa.ts` / `hanzomon.ts` / `fukutoshin.ts` / `minatomirai.ts` /
`rinkai.ts` / `denentoshi.ts` / `keikyu.ts` / `shonanShinjuku.ts` / `yokosuka.ts` /

- 駅 id プレフィックス: `e-` / `a-` / `z-` / `f-` / `mm-` / `r-` / `dt-` / `js-` / `kk-` / `jo-` / `jk-`

- 各駅の `transfers` には既存路線への逆リンクを含める（駅名マッチングで自動的に
  「のりかえ →」チップになる。既存路線側のデータ変更は不要）

### 変更ファイル

- `src/data/rideable.ts`: RIDEABLE レジストリに11路線を登録
- `src/data/lines.ts`:
  - `keihinTohoku` の表示名を「JR京浜東北・根岸線」に変更
  - 新路線の沿線で必要になった乗換案内専用路線を追加
    （JR武蔵野線・東急世田谷線・こどもの国線・東武アーバンパークライン・江ノ島電鉄・
    湘南モノレール・シーサイドライン・京急空港線・京急大師線・埼玉新都市交通ニューシャトル）
- `src/components/TitleScreen.tsx`: 路線数・駅数のハードコード（「乗車できる5路線」
  「NOW RUNNING — 6路線列挙」）を RIDEABLE から動的算出する形に変更
- 既存路線データへの戻りリンク追加（乗換を双方向にするため）:
  - `yamanote.ts` / `chuo.ts` / `keihinTohoku.ts` の東京 → 半蔵門線（大手町駅）
  - `yamanote.ts` / `ginza.ts` / `asakusa.ts` / `keihinTohoku.ts` の新橋 → 大江戸線（汐留駅）
  - `hibiya.ts` の築地 → 大江戸線（築地市場駅）
  - `ginza.ts` の溜池山王 → 丸ノ内線（国会議事堂前駅）※第2フェーズからの片方向リンクを解消

### 変更しないもの

- 地図描画（LoopMap / LinearMap）・ストア: 変更不要。
  47駅の京浜東北線もつづら折りレイアウト（1行7駅 × 7行）で描画できることを確認

  記載済みの `{ line: 'oedo' }` などが自動でタップ可能になる
