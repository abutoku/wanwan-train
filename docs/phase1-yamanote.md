# 第1フェーズ実装ドキュメント — 山手線（東京駅スタート）

作成日: 2026-07-04
ステータス: 実装完了

## 目的・スコープ

「どちら行き（内回り/外回り）に乗ればいいか」「あと何駅で着くか」を、
ドット絵チワワ（うる & ろい）が乗った電車で直感的に把握できるようにする。

第1フェーズの範囲:

- 山手線のみ（全30駅）、東京駅スタート
- 各停車駅の乗り換え案内を表示
- 内回り / 外回りの区別が一目でわかる表現
- 運転操作: **再生（押すと自動で進む／再度押すと停止）＋ 進む・戻る（1駅ずつ）**。
  地図上の駅タップは常時受付（タップするとそこまで移動、走行中は目的地を差し替え）
- タイトル画面（wanwan.png 使用、タイトルは「Wan Wan Train」）→ ゲーム画面の2画面構成
- ゲーム風だがスタイリッシュなダークUI（半透明ガラス調パネル + ドット絵チワワのアクセント）
- アプリとしては山手線限定ではないため、UI文言は路線非依存（現在の走行路線はヘッダーのバッジで表示）
- レスポンシブ対応（スマホ: 地図上・パネル下 / PC: 地図左・パネル右）
- テストコードは実装しない（仕様どおり）

## データモデル

```ts
// lines.ts
interface Line { name: string; color: string }   // color = ラインカラー(hex)
const LINES: Record<LineId, Line>

// yamanote.ts — 配列は「外回り（時計回り）」順。先頭 = 東京駅
interface Station {
  id: string
  name: string        // 例: 高輪ゲートウェイ
  kana: string        // 例: たかなわゲートウェイ
  en: string          // 例: Takanawa Gateway（訪日旅行者向け）
  number: string      // 駅ナンバリング 例: JY26
  transfers: { line: LineId; at?: string }[]  // at = 別名駅での乗換（例: 日比谷駅）
}
```

- 駅の並びは**外回り（時計回り）順**で保持。インデックス +1 = 外回りで1駅、-1 = 内回りで1駅。
- 駅ナンバリング（JY01東京〜JY30有楽町、内回り方向に増加）を正確に付与。

## 状態管理・移動ロジック（store.ts）

```
screen: 'title' | 'game'
direction: 'outer'(外回り=時計回り) | 'inner'(内回り=反時計回り)
currentIndex: number          // 現在駅（移動中は「次に着く駅」）
isMoving: boolean
isPlaying: boolean            // 再生（自動で進む）中か
destinationIndex: number | null   // タップ移動の目的地
arrivedIndex: number | null       // 到着演出用（2.2秒で消える）
```

- `_hop(delta)`: currentIndex を ±1 し、STEP_MS(900ms) 待つ（1駅ぶんの走行）
- `stepForward()` / `stepBackward()`: 選択中の方向へ1駅進む／逆向きに1駅もどる
- `travelTo(target)`: 駅タップで目的地をセット。常時受付で、走行中なら目的地を差し替えて続行。
  `_runTravel()` が現在の方向のまま1駅ずつホップして目的地まで進む（多重起動はガード）
- 再生: GameScreen の useEffect で「isPlaying かつ停車中なら AUTO_DWELL_MS(1.8s) 後に stepForward」を繰り返す
- 移動中は方向切替・進む/戻る・タイトル復帰を不可にする（駅タップのみ可）

タップ移動の残り駅数: `外回り: (to-from+30)%30 / 内回り: (from-to+30)%30` を表示（「あと◯えき」）。

## 地図描画（LoopMap / Train）

- SVG viewBox 1000×1000。正円（r=300）で描画
- 駅は等間隔（12°刻み）に配置。東京駅を右端（0°）とし、時計回り＝外回り順
  → 実地理と同様に 品川が下・新宿が左・田端が上・上野が右上 に来る
- **複線表現**: 外側トラック（外回り用）と内側トラック（内回り用）の2本の円を描画。
  電車は選択中の方向のトラック上を走る（方向切替でトラック間をアニメーション移動）
- **進行方向の可視化**: 選択中のトラック上を白い破線が進行方向に流れるCSSアニメーション
- 駅ラベルは放射状に回転配置（左半分は180°反転して読める向きに）
- **駅のタップ判定**: 駅ごとに12°ぶんの円環セクター（線路の内側〜ラベルの外側）を
  透明パスとして張り、隣駅と重ならず隙間なくタイル。スマホでも駅名ごとタップ可能。
  ホバー/タップ時は駅ドットが拡大しラベルが明るくなるフィードバック付き
- 電車スプライト: ピクセル調の車両（銀ボディ＋ウグイス色帯）に窓2つ、
  uru.png / roi.png のチワワが窓から大きく乗り出して乗車（車体より頭が出るサイズ）。
  `image-rendering: pixelated` でドット感維持
- 電車の向き: 円の接線角度に追従。上下逆さにならないよう ±90°を超えたら
  180°回転 + 左右反転（scaleX(-1)）で常に正立
- 地図中央にオーバーレイで「いまのえき／つぎは◯◯／あと◯えき／とうちゃく！」を大きく表示

## 仕様解釈・判断メモ

- START.md の「自動で進む／ボタン操作の3つ」は、当初3モード切替で実装したが、
  レビューを受けて **モードレス**（再生ボタン＋進む/戻るボタン＋常時駅タップ受付）に変更
- タップ移動は「選択中の方向のまま」進む（最短方向に自動で切り替えない）。
  → どちら向きに乗るべきかをユーザー自身が学べる、という本アプリの目的を優先。
  残り駅数の表示で「逆向きだと遠い」ことにも気づける
- 駅の配置は等間隔（ゲーム画面としての見やすさ優先）。実座標配置は将来検討
- 駅間の所要時間は一律900ms（ゲーム的表現）
