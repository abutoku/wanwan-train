# Wan Wan Train 🐕🚃

チワワ「うる」と「ろい」が乗った電車で、東京の路線をめぐる路線図アプリ。

「どちら行き（向き）に乗ればいいか」「あと何駅で着くか」を、
電車が路線図上を実際に走る様子で直感的に把握できます。

## 主な機能

- **乗車可能6路線・141駅** — JR山手線 / JR中央線(快速) / 東京メトロ銀座線・丸ノ内線・日比谷線 /
  東急東横線。駅ナンバリング・公式ラインカラーを再現
- **運転操作** — 再生（各駅に停車しながら自動で進む）、進む / 戻る（1駅ずつ）、
  駅タップ（途中駅で止まらず一気に目的地まで移動。残り駅数を表示）
- **方向がひと目でわかる** — 山手線は内回り / 外回りの複線表現、直線路線は「〜方面」。
  進行方向に破線が流れる
- **タップで乗り換え** — 停車中に乗り換え案内のチップをタップすると、その路線の対応する駅へ。
  乗車できない路線も公式ラインカラー付きの案内チップで表示
- **種別（停車駅）表示** — 快速・特快・急行などを選ぶと通過駅がうすく表示され、
  駅ごとの「とまる / 通過」も確認できる
- **出発駅の選択・駅名検索** — タイトル画面で出発駅を選択。
  駅名・かな・ローマ字・駅ナンバリングの部分一致で検索できる
- **チワワの演出** — 走行中は うる と ろい がぴょこぴょこ揺れて線路に肉球の足あとが残り、
  到着すると「わん！」の吹き出しと肉球がはじける
- **PWA対応** — ホーム画面に追加してアプリとして起動でき、オフラインでも路線図・検索・乗換案内が使える
- **レスポンシブ対応** — スマホは地図上・パネル下、PCは地図左・パネル右

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```
