# Wan Wan Train 🐕🚃

チワワ「うる」と「ろい」が乗った電車で、東京の路線をめぐる路線図アプリ。

「どちら行き（向き）に乗ればいいか」「あと何駅で着くか」を、
電車が路線図上を実際に走る様子で直感的に把握できます。

**🚃 公開中: https://wanwan-train.pages.dev**

## 機能

### 路線の追加（第9フェーズ: 完了）

- **乗車可能路線が6路線 → 17路線・377駅に**。新たに追加した11路線:
  - 都営地下鉄: 大江戸線（38駅）・浅草線（20駅）
  - 東京メトロ: 半蔵門線（14駅）・副都心線（16駅）
  - JR: 京浜東北・根岸線（47駅）・横須賀線（19駅）・湘南新宿ライン（16駅）
  - 私鉄ほか: 東急田園都市線（27駅）・京急本線（25駅）・みなとみらい線（6駅）・りんかい線（8駅)
- 種別（停車駅ビュー）も収録: 京浜東北線快速・湘南新宿ライン快速/特別快速・
  副都心線急行/通勤急行・田園都市線急行/準急・京急快特/特急・
  みなとみらい線特急/急行・浅草線エアポート快特
- 既存駅の乗換案内チップが自動でタップ可能に（例: 渋谷 → 半蔵門線・田園都市線、
  浜松町 → 大門（大江戸線）、横浜 → みなとみらい線・京急）

### 挙動の変更・文言修正（第8フェーズ: 完了）

- **駅タップで目的地まで一気に移動** — 途中駅で止まらず、1本の連続アニメーションで
  目的地へ直行（移動距離に応じて所要時間が伸びる「急行」の挙動）
- タイトル画面ほか各所の文言を調整（「ドット絵の」削除、キャッチコピー修正、
  「出発駅」「駅名で検索」の表記に統一）

### 自動デプロイ（第7フェーズ: 完了）

- **main ブランチへのマージで本番へ自動反映** — GitHub Actions が
  ビルド（型チェック含む）→ Cloudflare Pages へのデプロイを実行
- Actions タブから手動実行（workflow_dispatch）も可能

### PWA化（第6フェーズ: 完了）

- **ホーム画面に追加してアプリとして起動可能**（スタンドアロン表示・チワワのアイコン）
- **オフライン対応** — 全アセットをプリキャッシュし、電波の弱い駅ホームや地下でも
  路線図・駅検索・乗換案内が動作（Webフォントは2回目の訪問以降オフライン利用可）
- Service Worker は新バージョン検出時に自動更新（vite-plugin-pwa / Workbox）

### デプロイ（第5フェーズ: 完了）

- **Cloudflare Pages で公開** — https://wanwan-train.pages.dev
- wrangler CLI による直接アップロード方式（`npm run deploy` でビルド + 本番反映）

### 快速・特快などの停車駅表示（第4フェーズ: 完了）

- **JR中央線(快速) を追加** — 東京 JC01 〜 高尾 JC24 の24駅が乗車可能に（乗車可能6路線・141駅）
- **停車駅ビュー** — 種別（中央線: 快速 平日/土休日・中央特快・通勤特快、
  東横線: 各駅停車・急行・通勤特急・特急）を選ぶと、
  地図上で通過駅がうすく表示され、停車駅に種別カラーのリングが付く
- **「この駅にとまる電車」** — 駅情報パネルに種別ごとの「とまる／通過」を一覧表示
- 運転時間帯が限られる種別（通勤特快・通勤特急）は注記付き。
  全列車が各駅にとまる路線（山手線・地下鉄3線）では種別UIは表示されない

### スタート駅の選択・駅名検索（第3フェーズ: 完了）

- **タイトル画面でスタート駅を選択** — 「出発駅」パネルで出発する路線・駅を選べる
  （未選択なら従来どおり山手線・東京駅スタート）
- **フリーワード駅名検索** — 駅名・かな・ローマ字・駅ナンバリングの部分一致で検索
  （「渋谷」「シブヤ」「shibuya」「渋谷駅」いずれでもヒット）
- **同名駅は路線ごとに候補表示** — 例: 渋谷 → JR山手線 / 銀座線 / 東急東横線 の3件から選ぶ

### 路線と乗り換え（第2フェーズ: 完了）

- **乗車可能6路線** — JR山手線（30駅）・JR中央線 快速（24駅・第4フェーズ追加）・
  東京メトロ銀座線（19駅）・丸ノ内線（25駅）・日比谷線（22駅）・東急東横線（21駅）。
  駅ナンバリング付き
- **タップで乗り換え** — 停車中に乗り換え案内の「のりかえ →」チップをタップすると
  その路線の対応する駅に乗り換え（別名駅乗換にも対応。例: 上野広小路 → JR御徒町）
- **環状 / 直線の2種類の地図** — 山手線は円形ループ、地下鉄・東横線はつづら折り配置
- **方向表示** — 山手線は内回り/外回り、直線路線は「〜方面」（終点で自動停止・進む無効化）
- 乗車できない路線（JR他線・都営・他私鉄など）も公式ラインカラー付きの案内チップで表示

### 基本操作（第1フェーズ: 完了）

- **内回り / 外回りの複線表現** — 選択中の方向のトラックを電車が走り、進行方向に破線が流れる
- **モードレスな運転操作**
  - 再生ボタン: 押すと各駅に停車しながら自動で進む（再度押すと停止）
  - 進む / 戻る: 1駅ずつ移動
  - 駅タップ: いつでも地図上の駅をタップすると、途中駅で止まらず一気にそこまで移動
    （残り駅数を表示。直線路線では方向も自動で切り替え）
- **レスポンシブ対応** — スマホは地図上・パネル下、PCは地図左・パネル右
- スタイリッシュなダークUI + チワワ

## 起動方法

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm run preview  # ビルド結果のプレビュー
```

## デプロイ

**main ブランチにマージすると GitHub Actions が自動で本番デプロイします**
（Cloudflare Pages プロジェクト `wanwan-train`）。

手動デプロイ（フォールバック）も引き続き可能です:

```bash
npx wrangler login   # 初回のみ: Cloudflare 認証
npm run deploy       # ビルド + 本番デプロイ（--branch=main）
```
